\chapter{Fundamentals}
\label{chap:basics}

This chapter builds a first Ymir program and follows it from a text file to a
running executable. Along the way it introduces the tools -- the compiler
\token{gyc}, the build system Gyllir, and the intermediate language the compiler
uses to describe what a program really does -- and explains how the rest of the
book is arranged.

\minitoc%

Getting from source code to a program takes three steps. A text editor produces
\emph{source files}, text files whose content follows the grammar and the
semantics of Ymir. The compiler reads those and emits \emph{object files}, which
hold machine code. A linker then joins the object files into a single executable,
pulling in whatever the program borrows from libraries -- the standard library
among them -- which ship as archives of object files compiled in advance. In
practice the compiler is asked to do both jobs at once, and the linker is never
invoked by hand.

A source file is encoded in \textit{utf-8} and carries the extension
\textit{.yr}. The extension is not decoration: it is how the compiler decides
which language it is reading. Ymir was designed to interoperate with C, so the
same compiler also accepts C source files, which it recognises by their
\textit{.c} extension.

Source code that breaks the syntax or the semantics of the language does not
compile. The compiler reports what it found and where, in messages meant to be
read by a person and acted on directly.
