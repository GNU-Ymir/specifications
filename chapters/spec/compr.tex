\chapter{Comprehensions}%
\label{chap:compr}

A comprehension builds a new value from an iteration, in a single expression:
the loop, the element it produces, and the value it fills are written together.
This chapter specifies list comprehension, which builds arrays, slices and
tuples.

A comprehension iterates over the same values as a \token{for} loop
(Section~\ref{sec:flow:for_loop}), and follows the same rules to do so.
