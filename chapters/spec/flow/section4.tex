\section{Infinite loop}%
\label{sec:flow:inf_loop}

\token{loop} evaluates its block repeatedly, with no condition. It stops only
through \token{break}, or through an exit of the whole function:
\token{return}, \token{throw} or \token{panic}. It suits a loop whose exit is
decided in the middle or at the end of its body, and a loop that has no end,
such as a server waiting for connections.

\subsection{Grammar}

\begin{lstlisting}[style=grammarVerb]
loop_expression     := 'loop' block
break_expression    := 'break' expression? ';'
continue_expression := 'continue' ';'
\end{lstlisting}

The body of a \token{loop} is always a block: unlike a conditional, it cannot be
a single expression. \token{break} and \token{continue} have no label, and the
value of a \token{break} is optional.

\subsection{Evaluation}

The block is evaluated, then evaluated again, indefinitely. Each evaluation is an
\textit{iteration}, and opens a new scope: a variable declared in the block is
created again at each iteration.

\subsubsection{Breaking a loop}
\label{sec:flow:breaking_loops}

\token{break} ends the innermost loop that contains it -- \token{loop},
\token{while} or \token{for} -- and evaluation resumes after that loop. The
loops that enclose it are unaffected. In the next example, the inner loop runs a
single iteration each time the outer one does, so the output alternates
\textit{Inner loop} and \textit{Outer loop}.

\begin{lstlisting}[style=coloredverbatim]
loop {
  loop {
    println("Inner loop");
    break;
  }
  println("Outer loop");
}
\end{lstlisting}

There is no labelled \token{break}: leaving several loops at once takes a
\token{break} in each, or a \token{return}. \token{break} outside any loop is an
error, E4007.

\subsubsection{Skipping an iteration}
\label{sec:flow:continue}

\token{continue} ends the current iteration of the innermost loop that contains
it, and starts the next one. In a \token{loop}, the next iteration starts at once;
in a \token{while}, the condition is tested first
(Section~\ref{sec:flow:while_loop}); in a \token{for}, the iterator moves to the
next element (Section~\ref{sec:flow:for_loop}).

\begin{lstlisting}[style=coloredverbatim, caption=Skipping iterations with \token{continue}, label=lst:flow:continue]
fn main() {
  let mut i = 0;
  loop {
    i += 1;
    if i % 2 == 0 {
      continue; // skips the even numbers
    }
    if i > 7 {
      break;
    }
    println(i); // 1, 3, 5, 7
  }
}
\end{lstlisting}

\token{continue} outside any loop is an error, E4009.

\subsection{Value and type}

The value of a \token{loop} is given by the \token{break} that ends it:
\token{break e;} ends the loop with the value \token{e}. A loop has a value if
all its \token{break}s carry one; if none does, its type is \token{void}. A
mix of the two is an error. The
type is determined as for a conditional
(Section~\ref{sec:flow:cond_value_type}), with the \token{break}s in the role of
the branches: the type of the first \token{break} in source order, to which the
values of the others are implicitly cast.

\begin{lstlisting}[style=coloredverbatim, label=lst:flow:simple_loop_break, caption=Breaking a loop with a value]
let mut count = 0;

let x = loop {
  if (count == 10) {
    break count + 1;
  }

  count += 1;
};

assert(x == 11);
\end{lstlisting}

The implicit cast lets the \token{break}s carry values of compatible types that
are not equal. In the next example, the two values are instances of two
classes that share the ancestor \token{A}, and the loop is of type \token{\&A}.

\begin{lstlisting}[style=coloredverbatim, escapechar=@]
class A {
  pub self() {}
}

class B over A {
  pub self() {}
}

class C over A {
  pub self() {}
}

let mut count = 0;
let x = loop {
  if count == 1 {
    break copy B();
  } else if count == 10 {
    break copy C();
  }

  count += 1;
};

println(typeof(x)::typeid); // &(A), prefixed by the name of the module
\end{lstlisting}

A loop that no \token{break} ends has no value, and a variable cannot hold it
(E4039). A \token{break} with a value in a \token{while} or a \token{for} is an
error, since those loops have no value (Section~\ref{sec:flow:while_value}).

\subsubsection{Mutability of the value}

As for a conditional, the value of a loop takes the most restricted mutability
among the values of its \token{break}s. In the next example the value of the
\token{break} on line~8 is of type \token{mut [i32]}, more restricted than the
\token{mut [mut i32]} of line~6, so the loop is of type \token{mut [i32]}.

\begin{lstlisting}[style=coloredverbatim, escapechar=@]
let mut count = 1;
let a = copy [2, 3, 4];

let x = loop {
  if count == 1 {
    break copy [1, 2, 3];
  } else if count == 10 {
    break a;
  }

  count += 1;
};

println(x);
\end{lstlisting}

A \token{break} that moves borrowed mutable data must say so with \token{alias}.
The contract is then already accepted on the \token{break}, and is not repeated
in front of the \token{loop}.

\begin{lstlisting}[style=coloredverbatim, escapechar=@]
let mut count = 0;
let dmut a = copy [1, 2, 3];

let dmut x = loop { // no need for explicit /alias/
  if count == 10 {
    break alias a; // /alias/ is mandatory here
  }

  count += 1;
};

println(x);
\end{lstlisting}
