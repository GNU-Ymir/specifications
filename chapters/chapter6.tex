\chapter{Variables and memory management}
\label{chap:memory}

A variable is a name standing for a location in memory. Naming it reaches that
location, to read the value there or to write a new one.

Not every variable reaches it the same way, and not every variable is allowed to
do the same things once it arrives: a reference variable resolves to a location
belonging to something else, and a variable's mutability decides whether writing
is permitted at all. This chapter specifies the kinds of variable Ymir has, how
each is laid out in memory, and what each may do -- which together are how memory
is managed in the language.
