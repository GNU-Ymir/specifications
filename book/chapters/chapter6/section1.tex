\section{Preamble}
\label{sec:memory:preamble}

A variable is declared in one of three places: as a global variable
(Section~\ref{sec:global:global_variables}), as a function parameter
(Section~\ref{sec:global:function_parameters}), or as a local variable inside a
function body.

All three share two properties. Each has a symbolic name, and each has a type
that is fixed at the declaration and never changes afterwards. Where the value
itself lives does differ: on the stack for local variables and parameters, in the
text segment for globals, and on the heap for the borrowed part of any of the
three whose value borrows.
